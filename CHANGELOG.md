# Changelog

All notable changes to this project will be documented in this file.

## [1.0.4] - 2026-02-11
- Highlighted due dates in card list: overdue dates are red, due-today dates are yellow
- Added direct Markdown editing flow for cards via `Open` / `Open .md` in the VS Code editor
- Synced board state when webview regains focus after external card file edits

## [1.0.3] - 2026-01-31
- Auto-scroll while dragging cards to reach off-screen lists
- Added label management with colors, card label chips, and filtering
- Moved label search/create/edit/delete into a dedicated modal with confirmation
- Added confirmation modal for card deletion
